# PROJECT_STATE

## Утверждённые продуктовые решения

- Приложение — единый учебный кабинет Иосифа. Предмет является глобальным контекстом (`SubjectContext`): математика, английский или русский язык. Все разделы, данные и преподаватель синхронно зависят от него.
- Предмет выбирается только глобальным переключателем в шапке. Блока «Мои предметы» нет.
- Левое меню: Главная, Мои уроки, Домашнее задание, Проверочные работы, Результаты, Доска, Библиотека, Достижения.
- Главная содержит приветствие, ближайший урок, прогресс текущей темы, ближайшие занятия, последнюю завершённую еженедельную проверочную и последние достижения.
- «Все занятия» показывает месячный список прошедших и будущих уроков. Завершённые уроки остаются в истории, имеют подробную карточку и действие повторения сохранённых материалов.
- Для каждого активного предмета предусматривается одна проверочная работа в неделю. Проверочные работы и их архив — отдельный раздел; «Последние результаты» на Главной означает последнюю завершённую недельную проверочную.
- Домашнее задание — отдельный раздел с активной работой и доступным архивом.
- Достижения — лёгкий предметный мотивационный слой, а не игровая система.
- Математическая доска сохраняется как предметный режим общей доски; другие предметы получают собственные `BoardMode` и наборы инструментов.

## Разделение ролей

### SubjectTeacher

Ведёт урок, объясняет, задаёт учебные вопросы, проверяет ответы, реагирует на ошибки и обучает. Преподаватель не управляет интерфейсом приложения.

### DashboardAssistant

Отдельный архитектурный слой для навигации, смены разделов и предмета, открытия уроков, домашних и проверочных работ. На текущем этапе существуют только типизированный контракт и детерминированный каркас команд — без голоса, LLM и пользовательского образа.

Эти роли нельзя смешивать.

## Техническое состояние

- Текущая инфраструктура — Vite + React + TypeScript (не мигрируется на другой фреймворк).
- Маршрутизация использует History API и реальные статические entry points для GitHub Pages.
- Preview для внутренних pull request публикуется в отдельный Cloudflare Pages project; production GitHub Pages и его protected environment не используются для preview.
- Данные этого этапа находятся в `src/data/mock` и строго разделены по `SubjectId`.
- Внешние AI, voice, speech, avatar и production database интеграции не подключены.
